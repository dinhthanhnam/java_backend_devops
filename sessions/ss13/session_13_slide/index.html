01

Monitoring, Metrics & Kiến trúc Prometheus

© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

Production = Hộp đen?

Không có metrics = không có tầm nhìn

Không có giám sát

  • CPU VPS quá tải? — Không biết
  • RAM JVM cạn kiệt? — Không biết
  • API nào bị request đổ dồn? — Không biết

Có Prometheus

  • Metrics liên tục theo thời gian (Time-series)
  • Tự động phát hiện target DOWN
  • Dashboard trực quan + cảnh báo

Lưu ý

Vận hành mà không có Monitoring giống lái xe bịt mắt — chỉ biết sự cố khi đã va chạm.

Pull-based vs Push-based

Pull-based (Prometheus)

  • Server chủ động kéo dữ liệu định kỳ (HTTP GET)
  • Không bị DDoS từ client tải cao
  • Dễ phát hiện target DOWN
  • Phù hợp long-running services

Push-based (InfluxDB, Jaeger…)

  • Client đẩy dữ liệu về Server
  • Phù hợp short-lived jobs / Serverless
  • Server dễ bị quá tải khi ngàn client gửi dồn

Ghi nhớ

Micrometer = SLF4J cho metrics — lớp trừu tượng đo đạc trung gian.

© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

Cấu hình mã nguồn

build.gradle & application.yml

build.gradle groovy 
dependencies {
    // Actuator thu thập thông số JVM
    implementation 'org.springframework.boot:
        spring-boot-starter-actuator'

    // Dịch metrics sang Prometheus
    implementation 'io.micrometer:
        micrometer-registry-prometheus'
}
application.yml yaml 
management:
  endpoints:
    web:
      exposure:
        include: health, prometheus
  metrics:
    tags:
      application:
        ${spring.application.name}

Bảo mật Endpoint Actuator trên Production

SAI — Mở toang

  • include: "*" → Expose hết endpoint
  • /actuator/env → Lộ password DB, JWT Secret
  • /actuator/shutdown → Tắt app từ xa

ĐÚNG — Chọn lọc

  • Chỉ mở health, prometheus
  • Chặn port 8081/8083 bằng UFW
  • Chỉ Prometheus container nội bộ mới kéo được

Lưu ý

Expose include: "*" trên Production = Phơi bày toàn bộ sơ đồ kiến trúc cho hacker.

Triển khai Prometheus bằng Docker Compose

© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

Cấu trúc prometheus.yml

scrape_interval
Chu kỳ kéo metrics (15s)
job_name
Tên nhóm target
metrics_path
Đường dẫn endpoint
targets
Danh sách DNS:Port
prometheus.yml yaml 
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'quickbite-backend'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets:
          - 'user-service:8081'
          - 'order-service:8083'

Docker Compose cho Prometheus

Volume + Network, không expose port 9090

docker-compose.yml yaml 
prometheus:
  image: prom/prometheus:v2.45.0
  container_name: quickbite-prometheus
  volumes:
    - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
    - prometheus-data:/prometheus
  command:
    - '--config.file=/etc/prometheus/prometheus.yml'
    - '--storage.tsdb.path=/prometheus'
  networks:
    - quickbite-net
  # KHÔNG expose 9090 ra ngoài host

Cảnh báo

Giao diện web Prometheus KHÔNG có authentication. Expose port 9090 = bất kỳ ai cũng truy cập và xóa dữ liệu.

04

Node Exporter — Giám sát phần cứng VPS

© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

Node Exporter là gì?

Agent giám sát cấp hệ điều hành

  • Agent chính thức Prometheus cho Linux
  • Đo: CPU load, RAM, Disk I/O, Network
  • Cổng 9100, endpoint /metrics

Cơ chế

Mount Read-Only

  • /proc → /host/proc:ro — Tiến trình & RAM
  • /sys → /host/sys:ro — Phần cứng kernel
  • / → /rootfs:ro — Dung lượng ổ đĩa

Ghi nhớ

Bắt buộc mount :ro (Read-Only). Container chỉ đọc thông số, không can thiệp hệ thống host.

© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

So sánh

Node Exporter vs Spring Boot Actuator

Tiêu chí Node Exporter Actuator
Phạm vi Hệ điều hành VPS Máy ảo JVM
Chỉ số CPU, RAM vật lý, Disk, Network Heap, GC Pauses, HTTP Requests
Cài đặt 1 instance / VPS Tích hợp vào từng microservice
Endpoint :9100/metrics :PORT/actuator/prometheus
© 2026 By Rikkei Academy - Rikkei Education - All rights reserved.

Tích hợp Node Exporter

docker-compose.yml yaml 
node-exporter:
  image: prom/node-exporter:v1.6.0
  volumes:
    - /proc:/host/proc:ro
    - /sys:/host/sys:ro
    - /:/rootfs:ro
  command:
    - '--path.procfs=/host/proc'
    - '--path.sysfs=/host/sys'
  networks:
    - quickbite-net
prometheus.yml yaml 
- job_name: 'vps-hardware'
  metrics_path: '/metrics'
  static_configs:
    - targets:
        - 'node-exporter:9100'
